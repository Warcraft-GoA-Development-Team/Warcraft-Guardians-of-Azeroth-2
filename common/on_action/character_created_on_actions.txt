# On actions for character creation from other sources than birth (those are in child_birth_on_actions.txt), triggered automatically by the game

# For mods that want to intercept all cases when a character is created directly instead of born.
# Root is the newly created character
# scope:creation_reason is why the character was created, options (need to be prefixed with flag: in comparisons) are:
# 	script				- Created by the create_character effect
#	ruler_designer		- Created by the ruler designer, any spouse or children generated for the custom character also have this reason
# 	pool				- Created to populate the pool of wandering characters
# 	guests				- Created to be a guest that randomly appears at a court
# 	court_populator		- Created because a newly created court needed a courtier
# 	mercenary_companies	- Created to be the commander of a mercenary band
# The following five options are all automatically created new landed rulers:
# 	succession			- Created as the new ruler of a title after succession if no existing character was a valid heir and the title shouldn't be destroyed
# 	grant_titles		- Created when the AI wants to grant a county or barony away but no existing character is an appropriate recipient
# 	great_holy_war		- Created to hold a barony after a victorious Great Holy War
# 	migration			- A Herder created to hold titles left behind after nomadic migration
# 	save_file_fix		- Created to be the holder of a County to fix a save game having a county without a holder that can sometimes be caused by baronies changing county 
on_character_created = {
	effect = {
		##christian_clergy_learn_liturgical_language_effect = yes # Warcraft = yes
		# Warcraft 
		# Sets race trait (no gene)
		trigger_event = {
			id = WCRAC.10
			days = 1
		}
	}
}
