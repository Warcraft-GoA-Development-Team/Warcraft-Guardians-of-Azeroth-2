### Installation 
NOTE: The development build downloaded from github can be considered an Alpha. It is not guaranteed to be free from bugs and crashes, may break your saves between updates, and may make you unable to also run the release version. However, by testing the development build you are contributing to the ongoing work on GoA by providing our team with feedback. If you are willing to take on these responsibilities, message an admin on our discord about being added to the #open-testing channel or even getting the #ck3-tester role! [More information about being a tester can be found here](https://github.com/Warcraft-GoA-Development-Team/Warcraft-Guardians-of-Azeroth-2/wiki/How-to-be-Tester-(For-CK3)).
